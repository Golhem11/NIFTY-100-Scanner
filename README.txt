NIFTY 100 5-MINUTE SIGNAL SCANNER - AUTO START

1. Double-click RUN SCANNER.bat.
2. The scanner starts automatically; there is no Start/Stop button.
3. Keep this CMD window open while the scanner is running.
4. Closing the CMD window stops the scanner and sends the shutdown Telegram notification.
5. Refreshing or closing the browser tab does NOT stop the scanner.
6. Angel One + Telegram credentials are saved encrypted using Windows DPAPI in your local Windows profile.
7. If this is a new PC, the dashboard will show the secure first-run setup form. Enter the credentials once and they will be saved locally.
8. The scanner is scanner-only; no orders are placed.

Signal rules:
BUY: Close > SMA 60 AND CCI 20 < -192
SELL: Close < SMA 60 AND CCI 20 > +192
Only completed 5-minute candles are evaluated.

The package includes the Angel One SmartAPI Python dependency and checks dependencies before launch.
